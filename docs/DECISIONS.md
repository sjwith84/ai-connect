# Architecture Decisions

## 001 — Git 저장소를 프로젝트의 Source of Truth로 사용

**상태:** 채택

ChatGPT 대화의 컨텍스트는 영속적이지 않으므로 프로젝트의 현재 코드와 중요한 설계 지식을 대화에만 저장하지 않는다. Git repository의 코드와 Markdown 문서를 프로젝트의 지속적인 상태로 사용한다.

## 002 — 웹 채팅과 Git을 분리된 역할로 사용

**상태:** 채택

ChatGPT는 설계 토론, 설명, 추론, 구현 작업을 담당하고 GitHub는 실제 파일과 버전 기록을 담당한다. 이를 통해 채팅창을 바꿔도 프로젝트를 복원할 수 있게 한다.

## 003 — 튜토리얼은 의존성 없는 HTML로 시작

**상태:** 채택

첫 실험에서는 별도의 빌드 도구나 프레임워크 없이 `index.html` 하나를 브라우저에서 열어 실행할 수 있도록 한다. 목적은 Git과 AI 협업 구조를 검증하는 것이므로 기술적 복잡성을 최소화한다.
